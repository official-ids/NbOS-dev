# NexKey - вопросы и ответы (русский)

English version: [FAQ_en.md](FAQ_en.md). Полное руководство: [HELP_ru.md](HELP_ru.md).

## Общее

**Что такое NexKey одним предложением?**
Фоновая утилита, которая открывает любое приложение, сайт или файл по нажатию горячей клавиши по всей системе — даже когда её окно закрыто.

**Она бесплатная?**
Да, лицензия MIT разрешает свободное использование, изменение и распространение.

**Программа собирает какие-нибудь данные?**
Нет телеметрии, нет аналитики, нет аккаунтов. Единственный сетевой запрос — необязательная проверка обновлений к GitHub Releases.

**Какие системные требования?**
Windows 10/11 (x64) или macOS 10.15+ (Intel и Apple Silicon). Больше ничего.

## Хоткеи

**Можно назначить одну клавишу без модификаторов?**
Технически да, но NexKey предупредит: такой хоткей срабатывает при каждом нажатии по всей системе, даже когда вы печатаете. Лучше используйте сочетания вроде `Ctrl+Alt+Z`.

**Мой хоткей не работает. Что проверить?**
1. Связка включена (переключатель на карточке).
2. Глобальная пауза выключена (переключатель в боковой панели).
3. На карточке нет значка `!` — он означает, что сочетание занято другой программой.
4. Попробуйте другое сочетание.

**Какие сочетания безопасно использовать?**
`Ctrl+Alt+<клавиша>` почти не используется другими программами. Не стоит назначать `Ctrl+C`, `Alt+Tab`, одиночный `Win` и одиночные буквы.

**Может ли один хоткей запускать две вещи?**
Нет. Одно сочетание — одна связка. NexKey блокирует дубликаты при сохранении.

## Типы связок

**Что можно открывать?**
Приложения (`.exe`, `.bat`, `.cmd`, `.lnk`, `.app`), сайты (в браузере по умолчанию) и любые файлы или папки через системный обработчик по умолчанию.

**Хочу запускать zapret. Что именно добавлять?**
Тип «Приложение», путь — полный путь к `general.bat` (или `general.exe` — смотря что в вашей сборке). Включите «Запуск от администратора», если скрипт требует прав. Назначьте хоткей — готово. Пошаговое описание — в [HELP_ru.md](HELP_ru.md), раздел 4.

**Сайт откроется в браузере по умолчанию?**
Да. NexKey не встраивает свой браузер.

**Можно передать программе аргументы?**
Да — поле «Аргументы» в диалоге связки. Поддерживаются кавычки для путей с пробелами.

## Фоновая работа

**Переживёт ли перезагрузку?**
Да, если включено «Запускать вместе с системой». Это стандартный элемент входа ОС — после перезагрузки NexKey стартует в трее, и хоткеи готовы сразу.

**Как закрыть её полностью?**
Через меню иконки трея — «Выйти из NexKey». Кнопка закрытия окна по умолчанию лишь сворачивает приложение (меняется в настройках).

**Она замедляет компьютер?**
Нет. Это небольшая Electron-утилита, сидящая в памяти; в простое нагрузка на процессор нулевая.

**Конфигурация сохранится после удаления?**
Да. `%APPDATA%\nexkey\config.json` (Windows) или `~/Library/Application Support/nexkey/` (macOS) остаётся на месте, поэтому переустановка восстановит всё. Доступен также экспорт/импорт в JSON.

## Обновления и сборки

**Как обновляться?**
Настройки - О программе - «Проверить обновления», затем скачайте новый установщик с релиза и установите поверх старого. Ничего не удаляется.

**При запуске .bat-скрипта (например, zapret) вылезают окна консоли. Это нормально?**
Да, консоль - часть самого скрипта, убрать её полностью нельзя. NexKey запускает такие скрипты сразу свёрнутыми в панель задач, чтобы окно не вылезало поверх всего, и скрипт получает рабочий ввод - его меню работает как при обычном двойном клике. Окна отдельных сервисов, которые открывает сам скрипт (например, winws у zapret), тоже создаёт скрипт, а не NexKey. Нужен запуск вообще без окон - создайте бинд не на .bat, а прямо на .exe с нужными аргументами.

**Почему скрипт или программа запускается долго?**
NexKey передаёт запуск системе мгновенно (в nexkey.log видно время - обычно 10-100 мс). Всё остальное - меню самого скрипта, запрос UAC, проверка SmartScreen при первом запуске неподписанного файла - делает Windows или сам запускаемый файл.

**Windows показывает предупреждение SmartScreen при установке. Это опасно?**
Сборка не подписана платным сертификатом, поэтому Windows показывает стандартное предупреждение. Нажмите «Подробнее» - «Выполнить в любом случае». Исходный код открыт — установщик можно собрать и самому (`npm run dist:win`).

**macOS сообщает о разработчике, которого нельзя проверить.**
Один раз выполните: `xattr -cr /Applications/NexKey.app`.

**А под Linux можно собрать?**
Цель AppImage уже объявлена в `package.json` (`npm run dist` на Linux). Официально она пока не поддерживается и не тестируется, но помощь приветствуется.
