# NexKey - полное руководство (русский)

Версия 1.0.0. Доступны также: [English version](HELP_en.md), [FAQ](FAQ_ru.md), [Установка](INSTALL_ru.md).

## 1. Что такое NexKey

NexKey — фоновая утилита для Windows 10/11 и macOS, которая запускает приложения, открывает сайты и файлы или папки по нажатию горячей клавиши. Программа живёт в системном трее, стартует вместе с операционной системой и держит ваши хоткеи работающими круглосуточно.

Типичный сценарий: вы много раз в день запускаете `zapret\general.bat` (или любой другой скрипт или программу). С NexKey вы один раз назначаете на него `Ctrl+Alt+Z` и запускаете отовсюду одним нажатием.

## 2. Установка

Три способа получить NexKey — готовые сборки с GitHub Releases, портативная версия и сборка из исходников — описаны в [инструкции по установке](INSTALL_ru.md). На macOS неподписанное приложение нужно разрешить один раз после переноса в `/Applications`:

```bash
xattr -cr /Applications/NexKey.app
```

Затем откройте его как обычно (при необходимости — правой кнопкой - Открыть).

## 3. Первый запуск

1. NexKey стартует. Если включена настройка «Запуск свёрнутым в трей» (по умолчанию), окно не появится — вы увидите уведомление, что NexKey работает в фоне. Откройте окно через иконку в трее.
2. При самом первом запуске появляется короткое приветствие из трёх шагов.
3. Главное окно показывает список сочетаний; в боковой панели — навигация, глобальный переключатель хоткеев и индикатор состояния.

## 4. Создание сочетания

Нажмите **Добавить** (или `Ctrl+N` внутри приложения). В диалоге:

### 4.1 Название

Любая подпись, например «Запуск zapret» или «Рабочая папка». Отображается в списке и в уведомлениях о запуске.

### 4.2 Тип

| Тип | Что открывает | Как указать путь |
| --- | --- | --- |
| Приложение | `.exe`, `.bat`, `.cmd`, `.lnk`, на macOS также `.app` | кнопка «Обзор» или вставьте путь |
| Сайт | Браузер по умолчанию с адресом | введите адрес (`youtube.com` достаточно) |
| Файл / папка | Любой файл его программой по умолчанию или папку в проводнике | кнопка «Обзор» (файлы и папки) |

### 4.3 Путь или адрес

- **Приложение**: полный путь к исполняемому файлу. Файлы `.bat`/`.cmd` NexKey запускает через `cmd /c` из их собственной папки, поэтому скрипты вроде `general.bat` работают корректно.
- **Сайт**: `https://` добавляется автоматически; `youtube.com` превращается в `https://youtube.com`.
- **Файл / папка**: открывается системным обработчиком по умолчанию.

### 4.4 Аргументы (только для приложений)

Необязательные аргументы командной строки. Поддерживаются кавычки: `--mode fast "C:\path with spaces"`.

### 4.5 Запуск от администратора (Windows, только для приложений)

Запускает цель через PowerShell `Start-Process -Verb RunAs`. При каждом запуске появляется запрос UAC. Полезно для инструментов, требующих прав. Недоступно для ярлыков `.lnk` и на macOS.

### 4.6 Горячая клавиша

Нажмите на поле и задайте сочетание. Рекордер показывает нажатые модификаторы в виде клавиш.

Поддерживается: буквы `A`-`Z`, цифры, `F1`-`F12`, `Space`, стрелки, `Home`, `End`, `PageUp`, `PageDown`, `Insert`, `Delete`, знаки `` ` - = [ ] \ ; ' , . / `` и модификаторы `Ctrl`, `Alt`, `Shift`, `Win` (на macOS — `Cmd`).

Примечания:

- `Esc` отменяет запись, `Backspace` очищает текущее значение.
- Клавиша **без модификаторов** тоже работает, но NexKey предупредит: такой хоткей срабатывает при каждом нажатии по всей системе, даже когда вы печатаете текст.
- Рекомендация: всегда добавляйте хотя бы один модификатор (`Ctrl+Alt+...`), это исключает конфликты с набором текста и другими программами.
- Если сочетание уже занято другой программой, NexKey ничего не зарегистрирует и покажет предупреждение — карточка получит пунктирную рамку со значком `!`. Выберите другое сочетание.

### 4.7 Тестовый запуск

Кнопка **Тестовый запуск** в диалоге выполняет цель немедленно, без сохранения. Удобно проверить путь или аргументы.

## 5. Управление сочетаниями

Каждая карточка показывает иконку типа, название, путь, клавиши хоткея, счётчик запусков, время последнего запуска и управление:

| Управление | Действие |
| --- | --- |
| Переключатель | Включить или выключить связку (выключенная освобождает хоткей) |
| Значок запуска | Запустить связку прямо сейчас |
| Карандаш | Изменить связку |
| Стрелки вверх/вниз | Переместить связку в списке |
| Корзина | Удалить связку (с подтверждением) |

Над списком:

- **Поиск** — фильтрует по названию, пути и хоткею (клавиша `/` ставит курсор в поле).
- **Фильтры** — Все / Приложения / Сайты / Файлы.
- В заголовке видно, сколько связок активно.

## 6. Глобальная пауза

Переключатель **Хоткеи активны** в боковой панели приостанавливает все хоткеи разом, ничего не удаляя. На паузе:

- индикатор показывает «Хоткеи на паузе»;
- над списком появляется пунктирный баннер;
- пункт меню трея меняется на «Возобновить все хоткеи».

Состояние паузы сохраняется между перезапусками.

## 7. Настройки

### Общие

| Настройка | Значение |
| --- | --- |
| Язык | Русский или английский, применяется мгновенно |
| Тема | Чёрная (по умолчанию) или белая |
| Запускать вместе с системой | Стандартный элемент входа ОС; NexKey стартует после каждой перезагрузки |
| Запуск свёрнутым в трей | Окно при старте скрыто; уведомление подтвердит, что программа работает |
| Кнопка закрытия сворачивает в трей | Закрытие окна не завершает приложение |

### Поведение

| Настройка | Значение |
| --- | --- |
| Уведомления о запуске | Небольшое системное уведомление при каждом срабатывании хоткея |
| Проверять обновления автоматически | Один запрос к GitHub Releases при старте |

### Данные

| Действие | Значение |
| --- | --- |
| Экспорт конфигурации | Сохранить настройки и все связки в JSON-файл |
| Импорт конфигурации | Восстановить из JSON-файла, созданного NexKey |
| Сбросить статистику | Обнулить все счётчики запусков |
| Стереть всё | Удалить все связки и настройки (с двойным подтверждением) |

### О программе

Версия, кнопка «Проверить обновления» и ссылки: репозиторий GitHub, сайт 76 Школы, Telegram, почта.

## 8. Трей и фоновый режим

Иконка трея открывает меню: **Открыть NexKey**, **Приостановить / Возобновить все хоткеи**, **Запускать вместе с системой** (флажок), **Выйти из NexKey**. В Windows одиночный клик по иконке тоже открывает окно.

NexKey работает в единственном экземпляре: повторный запуск просто открывает существующее окно.

Чтобы завершить программу полностью, используйте меню трея (кнопка закрытия окна по умолчанию лишь сворачивает приложение).

## 9. Где хранятся данные

| ОС | Путь |
| --- | --- |
| Windows | `%APPDATA%\nexkey\config.json` |
| macOS | `~/Library/Application Support/nexkey/config.json` |

Рядом лежит резервная копия `config.json.bak`, а в `nexkey.log` — диагностические сообщения. Удаление программы не трогает конфиг, поэтому переустановка сохраняет все связки.

## 10. Обновления

**Проверить обновления** (Настройки - О программе, или автоматически при старте) сравнивает вашу версию с последним релизом на `github.com/official-ids/NbOS-dev/releases`. Если есть новее — появится уведомление со ссылкой на страницу Releases. NexKey никогда не скачивает и не устанавливает ничего сам.

## 11. Решение проблем

| Проблема | Причина и решение |
| --- | --- |
| Хоткей не работает | Сочетание занято другой программой. Запишите хоткей заново. Также проверьте, что связка включена и глобальная пауза выключена. |
| Значок `!` на карточке | NexKey не смог зарегистрировать этот хоткей (занят или некорректен). Выберите другое сочетание. |
| Программа не стартует с системой | Настройка работает для установленных сборок. Портативная версия и `npm start` автозапуск не регистрируют. |
| Уведомление не появляется | Проверьте «Уведомления о запуске» в Настройки - Поведение и разрешение системы на уведомления. |
| Скрипт `.bat` открывается и мгновенно закрывается | Запустите его вручную — если он закрывается и без NexKey, скрипту нужны аргументы или права администратора (включите «Запуск от администратора»). |
| macOS: приложение не открывается | Один раз выполните `xattr -cr /Applications/NexKey.app`. |
| Что-то ещё | Посмотрите `nexkey.log`, затем создайте issue или напишите на контакты ниже. |

## 12. Удаление

Windows: удалите NexKey через «Приложения и возможности». Папка конфигурации `%APPDATA%\nexkey` остаётся — при желании удалите её вручную для полной очистки.

macOS: перенесите `NexKey.app` в корзину. Для полной очистки удалите `~/Library/Application Support/nexkey`. Если автозапуск был включён — уберите NexKey из элементов входа.
