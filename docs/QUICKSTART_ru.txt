ЧТО ЭТО
  Фоновая утилита, которая открывает любое приложение,
  сайт или файл по нажатию горячей клавиши - по всей
  системе, 24/7.

УСТАНОВКА (Windows)
  1. Скачайте NexKey-Setup-1.0.0.exe с GitHub Releases:
     https://github.com/official-ids/NbOS-dev/releases
  2. Запустите, выберите папку, завершите установку.
  3. В настройках NexKey включите
     "Запускать вместе с системой".

ПЕРВОЕ СОЧЕТАНИЕ (пример: zapret)
  1. Откройте NexKey и нажмите "Добавить".
  2. Тип: Приложение.
  3. Путь: C:\Tools\zapret\general.bat  (ваш реальный путь)
  4. "Запуск от администратора" - включите, если нужно.
  5. Хоткей: нажмите на поле и задайте Ctrl+Alt+Z.
  6. Сохраните. Готово - Ctrl+Alt+Z работает отовсюду.

ПОЛЕЗНЫЕ КЛАВИШИ В ПРОГРАММЕ
  Ctrl+N   - новая связка
  /        - фокус в поиск
  Esc      - закрыть диалог

ГДЕ ЧТО НАХОДИТСЯ
  Иконка трея    - открыть, пауза хоткеев, автозапуск, выход
  Настройки      - язык RU/EN, тема чёрная/белая,
                   автозапуск, уведомления, экспорт/импорт
  Файл конфига   - %APPDATA%\nexkey\config.json
  Лог            - %APPDATA%\nexkey\nexkey.log

macOS
  После копирования приложения выполните один раз:
  xattr -cr /Applications/NexKey.app

ЕСЛИ ХОТКЕЙ НЕ РАБОТАЕТ
  - проверьте, что связка включена;
  - проверьте глобальную паузу (боковая панель);
  - если на карточке значок "!" - сочетание занято,
    выберите другое.
