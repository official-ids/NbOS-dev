# Установка NexKey (русский)

English version: [INSTALL_en.md](INSTALL_en.md).

NexKey работает на **Windows 10/11** и **macOS 10.15+**. Есть три способа установки.

## Способ 1 - готовые сборки с GitHub Releases (рекомендуется)

1. Откройте <https://github.com/official-ids/NbOS-dev/releases>.
2. В последнем релизе скачайте один файл:

| Файл | Что это |
| --- | --- |
| `NexKey-Setup-1.0.0.exe` | установщик для Windows (NSIS) |
| `NexKey-1.0.0-portable.exe` | портативная версия для Windows, без установки |
| `NexKey-1.0.0-arm64.dmg` | macOS, Apple Silicon (M1/M2/M3/M4) |
| `NexKey-1.0.0-x64.dmg` | macOS, Intel |

3. **Установщик Windows**: запустите файл, выберите папку установки, завершите. Создастся ярлык на рабочем столе, приложение сразу запустится. Включите «Запускать вместе с системой» в настройках для автозапуска 24/7.
4. **Портативная версия Windows**: просто запустите файл. Конфигурация хранится там же, в `%APPDATA%\nexkey`, но портативные сборки не регистрируют элемент автозапуска ОС — запускайте вручную или создайте ярлык в папке автозагрузки (`shell:startup`).
5. **macOS**: откройте `.dmg`, перенесите `NexKey.app` в `Applications`. Поскольку сборка не подписана платным сертификатом Apple, один раз выполните в терминале:

   ```bash
   xattr -cr /Applications/NexKey.app
   ```

   Затем откройте приложение как обычно.

## Способ 2 - сборка из исходников

Требования: [Node.js](https://nodejs.org) 18+ (рекомендуется Node 20 LTS) и Git.

```bash
# 1. Клонируйте репозиторий
git clone https://github.com/official-ids/NbOS-dev.git
cd NbOS-dev

# 2. Установите зависимости
npm install

# 3. Запуск в режиме разработки (проверка, необязательно)
npm start

# 4. Соберите установщик для своей ОС
npm run dist:win    # на Windows -> dist/NexKey-Setup-1.0.0.exe + portable
npm run dist:mac    # на macOS  -> dist/NexKey-1.0.0-<arch>.dmg
```

Примечания:

- Сборка `.exe` для Windows выполняется **на Windows**, `.dmg` — **на macOS**. Кросс-компиляция не поддерживается.
- Результат появляется в папке `dist/`.
- Сборка не подписана. Windows SmartScreen может показать предупреждение для скачанного установщика — нажмите «Подробнее» - «Выполнить в любом случае». На macOS используйте команду `xattr` выше.

## Способ 3 - автоматическая сборка через GitHub Actions

В репозитории есть CI-воркфлоу (`.github/workflows/build.yml`):

- каждый отправленный тег `v*` запускает сборку на раннерах Windows и macOS;
- готовые установщики автоматически прикрепляются к релизу на GitHub;
- на вкладке «Actions» можно запустить сборку вручную (`workflow_dispatch`) — артефакты появятся в сводке запуска.

Так вы всегда получаете свежие установщики, ничего не устанавливая локально. Чтобы релизы работали, репозиторий должен быть публичным либо иметь доступные минуты Actions.

## После установки - первые шаги

1. Запустите NexKey.
2. Если окно не появилось (по умолчанию «запуск свёрнутым»), найдите иконку в трее и кликните по ней.
3. В **Настройках** включите **Запускать вместе с системой**.
4. Создайте первое сочетание, например запуск zapret:

   - Тип: **Приложение**;
   - Путь: `C:\Tools\zapret\general.bat` (ваш реальный путь);
   - Запуск от администратора: включить, если скрипту нужны права;
   - Горячая клавиша: `Ctrl+Alt+Z`;
   - Сохранить.

Нажмите `Ctrl+Alt+Z` из любого окна — скрипт запустится. Перезагрузите ПК и проверьте, что иконка в трее появилась снова сама.

## Обновление

NexKey проверяет GitHub Releases на новую версию (Настройки - О программе - **Проверить обновления**, или автоматически). Скачайте новый установщик со страницы релиза и установите поверх старого — настройки и связки сохранятся.

## Удаление

- Windows: «Приложения и возможности» - NexKey - Удалить. Папка конфигурации `%APPDATA%\nexkey` остаётся; для полной очистки удалите её вручную.
- macOS: перенесите `NexKey.app` в корзину и для полной очистки удалите `~/Library/Application Support/nexkey`.
